# @lp/contracts

Draft of the `core-api` contract (SDD-00 §8) so the web app can be built contract-first against a mock server.

```
openapi/core-api.yaml        the contract (source of truth)
src/generated/core-api.d.ts  generated by `pnpm gen` (openapi-typescript), committed
src/index.ts                 type helpers: Schemas, OperationResponse, OperationQuery, OperationBody
src/openapi.ts               runtime loader of the YAML (mock server, tooling)
CHANGE_REQUESTS.md           requests for endpoints/fields missing from the contract
```

Commands: `pnpm gen` (regenerate), `pnpm gen:check` (CI drift check), `pnpm lint` (redocly).

Ownership: after freeze this package moves to the contracts repository; the web app keeps importing `@lp/contracts`.
